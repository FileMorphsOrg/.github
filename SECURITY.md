# Security policy

FileMorphs tools run in your browser. Your files are processed on your device and are not uploaded to a server, so most reports are about the website or the tools themselves.

## Report a vulnerability

Use the **Report a vulnerability** button on the issue tracker:
https://github.com/FileMorphsOrg/filemorphs/security/advisories/new

The report is private: only the FileMorphs team can see it. Don't open a public issue for a security problem.

If you can't use GitHub, email support@filemorphs.com.

## What to include

- The page or tool, and your browser and version
- Steps to reproduce the problem
- What an attacker could do with it

Don't send real client files or confidential documents. Use a sample file that shows the problem.

## Other private matters

For a problem that only shows with a confidential file, or anything else you don't want to post in public, email support@filemorphs.com.
