# FileMorphs

**Private file tools that run in your browser.** [filemorphs.com](https://filemorphs.com)

FileMorphs edits your files on your own device. The file is not uploaded to a server: the work runs in your browser with WebAssembly. PDFs and images today, with more file types on the way.

## Tools

- [PDF editor](https://filemorphs.com/tools/pdf-editor): edit, sign, redact, merge, split, compress and protect PDFs
- [Compare PDF](https://filemorphs.com/tools/compare-pdf): see what changed between two PDFs
- [Image editor](https://filemorphs.com/tools/image-editor): crop, mark up and redact photos, screenshots and scans

Free, no account, no watermark. Available in English, Spanish, German, Italian and French.

## Who it is for

Accountants, bookkeepers and anyone who handles client documents and can't send them to an unknown upload site.

## Report a problem or ask for a tool

- [Discussions](https://github.com/FileMorphsOrg/filemorphs/discussions) for questions and ideas

The tracker is public, so don't attach confidential files. For private matters, email support@filemorphs.com.
